# Gold News Straddle — แกะเทคนิคจากคลิป + Backtest

แกะเทคนิคที่เห็นในคลิป (MT5 มือถือ, `XAUUSD-ECN`, กราฟ M1, แคปชั่น
*"ea ready for news nfp"* — @eafxidy) แล้วเขียนโค้ด backtest ย้อนหลังกับ
ข้อมูลจริง 108 ครั้งของการประกาศ NFP ตั้งแต่ปี 2017 ถึง สิงหาคม 2026

---

## 1. คลิปทำอะไรอยู่

เฟรมจากคลิปบอกครบทุกอย่าง:

| เวลาในคลิป | สิ่งที่เห็นบนจอ |
|---|---|
| 0:00 | ราคา 4405.11/4405.21 · มีไม้ `SELL 0.01` เปิดอยู่ที่ 4406.45 (+1.24 USD) · มี pending `BUY STOP 0.01` ที่ 4405.88 |

สรุปกลไก: **News Straddle** — วาง pending stop order คร่อมราคาไว้ทั้งสองข้าง
ก่อนข่าวออก ข่าวออกราคาวิ่ง ฝั่งที่ถูกทางถูกยิงเข้า แล้วปล่อยให้วิ่ง

— ช่วง 50.69 USD ในนาทีเดียว ตรงกับกราฟและตัวเลขในคลิปทุกอย่าง

เพราะเป็นข่าวเวลา 08:30 ET เหมือนกัน)

## 2. แกะเป็นขั้นตอน

1. **เลือกข่าว** — ข่าวแรง เวลา 08:30 นิวยอร์ก (NFP วันศุกร์แรกของเดือน, CPI)
   = 12:30 UTC ช่วง DST / 13:30 UTC ช่วงฤดูหนาว
2. **T‑1 นาที** อ่านราคากลาง (mid) แล้ววาง pending สองไม้พร้อมกัน
   * `BUY STOP` ที่ mid **+ D**
   * `SELL STOP` ที่ mid **− D**
   * ในคลิป D ≈ 0.6–1.0 USD, lot 0.01 ทั้งสองข้าง
3. **ไม่ตัดไม้ตรงข้าม (ไม่ใช่ OCO)** — คลิปโชว์ชัดว่าเปิดสองขาพร้อมกันได้
   (ต้องเป็นบัญชี hedging)
4. **T+0** ข่าวออก สเปรดถ่าง ราคากระชาก ฝั่งใดฝั่งหนึ่ง (หรือทั้งสอง) ถูกยิง
5. **ตัดขาดทุนสั้น** ฝั่งที่ผิดทางโดน SL ภายใน ~1 นาที
6. **ปล่อยฝั่งที่ถูกทางวิ่ง** ด้วย trailing stop หรือถือครบเวลาแล้วปิด
7. **T+5 นาที** ไม้ที่ยังไม่ถูกยิง ให้ลบทิ้ง (กันโดนลากในช่วงราคาสะบัดกลับ)

> พารามิเตอร์ที่ **ไม่มีทางรู้แน่** จากคลิป: ค่า SL/TP/trailing ที่แท้จริง —
> คลิปไม่ได้โชว์เส้น SL/TP ดังนั้นในโค้ดจึงทำเป็นพารามิเตอร์แล้ว sweep หาเอง

## 3. ข้อมูลและแบบจำลอง

* **ข้อมูล** — XAUUSD M1 จาก terminal MT5 ของ Exness (symbol `XAUUSDm`),
  2017‑04‑28 → 2026‑08‑18, 3.27 ล้านแท่ง
  ([sherwynjoel/xauusd-historical-data](https://github.com/sherwynjoel/xauusd-historical-data))
  ราคาที่เก็บเป็น **bid** และมีคอลัมน์ `spread` จริงติดมาด้วย
* **ปฏิทิน** — ศุกร์แรกของเดือน + ปรับตามความเป็นจริง (วันหยุด 4 ก.ค.,
  ปีใหม่, และช่วง shutdown ปลายปี 2025 ที่ BLS เลื่อนประกาศ)
  ทุก override ยืนยันกับข้อมูลราคาแล้ว → เหลือ **108 เหตุการณ์**
* **การจำลองการยิงคำสั่ง** — เดินตาม *เส้นทางในแท่ง* ไม่ใช่แค่ high/low:
  แท่งเขียวเดิน `open → low → high → close`, แท่งแดงเดิน `open → high → low → close`
  จุดนี้สำคัญมาก เพราะในนาทีที่ข่าวออก **ทั้ง BUY STOP และ SELL STOP อยู่ในแท่งเดียวกัน**
  ลำดับการโดนแตะเป็นตัวตัดสินผลของไม้นั้น
* **สเปรดคิดรอบ mid** — bid = mid − s/2, ask = mid + s/2 ทำให้เวลาสเปรดถ่าง
  ask วิ่งขึ้นและ bid วิ่งลงพร้อมกันเหมือนของจริง (สเปรดถ่างอย่างเดียว
  ก็ยิง buy stop ได้ — เกิดขึ้นจริงตอนข่าว)
* **ต้นทุนที่คิด** — สเปรดปกติ (จากข้อมูล, floor 0.16) + สเปรดข่าว 0.80 USD
  ใน 3 นาทีแรก + slippage `0.05 + 10% ของช่วงแท่งที่ยิง` (cap 2.00) +
  ค่าคอม 3.50 USD/lot/ข้าง

## 4. ผล backtest

### A. ตั้งค่าตามคลิป (D = 0.60, SL 3.00, trailing 3.00, 0.01 lot, hedge)

| | ทั้งหมด | 2017–2022 | 2023–2026 |
|---|---|---|---|
| จำนวนข่าว | 108 | 67 | 41 |
| จำนวนไม้ | 169 | 101 | 68 |
| กำไรสุทธิ | **+187.81 USD** | −20.27 | +208.08 |
| ต่อข่าว | +1.74 USD | −0.30 | +5.08 |
| Profit factor | 1.58 | 0.89 | 2.57 |
| ชนะ (รายข่าว) | 50.0 % | 46.3 % | 56.1 % |
| DD สูงสุด | 59.50 USD | 59.50 | 24.11 |
| t‑stat | 2.07 | −0.47 | 2.75 |

รายปี: 2017 +15 · 2018 −4 · 2019 −5 · **2020 −36** · 2021 +18 · 2022 −8 ·
2023 +5 · 2024 +46 · 2025 +51 · 2026 +106

**ปัญหาของค่าคงที่:** ทองปี 2017 อยู่ที่ 1,250 USD ปี 2026 อยู่ที่ 4,500 USD
ระยะ 0.60 USD จึงเป็นคนละกลยุทธ์กันคนละยุค — กำไรเกือบทั้งหมดมาจากปี 2024+

### B. ปรับระยะให้สเกลตามความผันผวน (แนะนำ)

ให้ทุกระยะเป็น **สัดส่วนของ `unit`** = ช่วงราคา (high−low) ของ 120 นาที
*ก่อน* ข่าวออก (ข้อมูลที่รู้ล่วงหน้าจริง ไม่ใช่ look‑ahead)

เลือกค่าโดยดู **เฉพาะ 2017–2022** แล้วค่อยเอาไปวัดกับ 2023–2026:
`D = 0.35 × unit`, `SL = 0.25 × unit`, ไม่มี TP, ถือ 30 นาทีแล้วปิด, hedge,
ความเสี่ยงคงที่ 10 USD ต่อไม้

| | ทั้งหมด | 2017–2022 (เลือกจากตรงนี้) | 2023–2026 (ไม่เคยเห็น) |
|---|---|---|---|
| กำไรสุทธิ | **+1,922 USD** | +889 | +1,033 |
| ต่อข่าว | +1.78 R | +1.33 R | +2.52 R |
| Profit factor | 2.61 | 2.03 | 4.12 |
| ชนะ (รายไม้) | 31.4 % | 25.3 % | 42.9 % |
| กำไรเฉลี่ย/ขาดทุนเฉลี่ย | 82.04 / −14.40 | | |
| DD สูงสุด | 148.91 USD | | |
| t‑stat | 3.30 | 1.96 | 2.84 |

**กำไรทุกปี 9 จาก 10 ปี** (ขาดทุนเฉพาะ 2020 −14 USD)

### C. ความทนทาน (sweep 720 ชุดพารามิเตอร์)

* 20 ชุดที่ดีที่สุดในช่วง in‑sample → **กำไร out‑of‑sample ครบทั้ง 20/20**
  (มัธยฐาน +2.42 R ต่อข่าว)
* ทั้ง 720 ชุด → กำไร out‑of‑sample **86 % (fixed) / 89 % (vol)**
* ไม่ใช่ค่าที่ fluke — รูปทรงของกลยุทธ์ (SL สั้น, ไม่ตั้ง TP, ถือ 15–30 นาที,
  ปล่อยให้ติดสองขาได้) ชนะแทบทุกการตั้งค่า

### D. ต้นทุนคือตัวตัดสิน

| สเปรดข่าว | slippage | กำไรสุทธิ | PF |
|---|---|---|---|
| 0.30 | 0.05 + 0 %, cap 0.5 | +425.60 | 3.14 |
| 0.80 | 0.05 + 10 %, cap 2.0 | **+187.81** | 1.58 |
| 0.80 | 0.05 + 25 %, cap 5.0 | −59.30 | 0.87 |
| 1.50 | 0.05 + 25 %, cap 5.0 | −288.35 | 0.55 |
| 3.00 | 0.05 + 50 %, cap 10.0 | −907.28 | 0.17 |

**เกินครึ่งของ edge หายไปกับ execution** ถ้าโบรกถ่างสเปรดเกิน ~1.5 USD
หรือ slippage เกิน 25 % ของช่วงแท่ง กลยุทธ์นี้ติดลบทันที

### E. Placebo — ไม่มีข่าว ไม่มี edge

ยิงกลยุทธ์เดิม เวลาเดิม (08:30 ET) แต่เป็น **วันอังคารใกล้วันที่ 20**
ซึ่งไม่มีข่าวใหญ่ 111 ครั้ง:

`กำไรสุทธิ −154.02 USD · PF 0.57 · ชนะ 28.8 % · t = −2.95`

→ edge มาจากข่าวจริง ๆ ไม่ใช่จากตัวกลไก

### F. เล่นซ้ำเหตุการณ์ในคลิป (2026‑08‑12 12:30 UTC)

```
long  in 4429.88 @12:30  ->  out 4424.88 @12:30  (stop)   -5.07 USD
short in 4424.68 @12:30  ->  out 4399.51 @12:31  (stop)  +25.10 USD
                                                     net +20.03 USD
```

ตรงกับคลิปที่โชว์ไม้ SELL กำไรลอย +33.84 USD (คลิปยังไม่ปิดไม้,
โมเดลนี้ใช้ trailing stop เลยปิดที่ +25.10)

## 5. สิ่งที่ต้องรู้ก่อนเอาไปใช้

* **เทรดปีละ ~12 ครั้ง** — ตั้งค่าตามคลิปที่ 0.01 lot ได้กำไรรวม 188 USD
  ใน 9 ปี ≈ **21 USD/ปี** จะมีความหมายต้องขยาย size ซึ่งขยาย risk ตามไปด้วย
* **ผลตอบแทนกระจุกตัว** — ชุดตามคลิป: 5 ข่าวที่ดีที่สุดคิดเป็น **83 %**
  ของกำไรทั้งหมด (3 ข่าวแรก 54 %) ชุดสเกลตามผันผวนกระจายกว่าแต่ก็ยังกระจุก
  (top‑5 = 44 %, top‑10 = 76 %) พลาดไม่กี่ครั้ง ผลเปลี่ยนไปคนละเรื่อง
* **Backtest บนแท่ง M1 ไม่ใช่ tick** — ราคาที่ยิงจริงในวินาทีข่าวออก
  อาจแย่กว่านี้ ตาราง D คือขอบเขตของความเสียหายนั้น
* **โบรกจำนวนมากห้ามเทรดข่าว** — ขยาย stop level, ถ่างสเปรด, requote,
  หรือปิด pending ก่อนข่าว ถ้าเจอแบบนั้นผลจริงจะไม่เหมือน backtest
* **ต้องเป็นบัญชี hedging** (MT5 netting เปิดสองขาไม่ได้)
* นี่คือการวิเคราะห์เชิงเทคนิคและสถิติ **ไม่ใช่คำแนะนำการลงทุน**
  ผลย้อนหลังไม่รับประกันอนาคต
